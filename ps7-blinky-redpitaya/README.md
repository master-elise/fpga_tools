## PS7 control of the Red Pitaya PL-connected LEDs

Copied from ``ps7-blinky-digilent-pynqz1`` from https://github.com/openXC7/demo-projects

```
make bitbin
```
after ``make`` to generate the ``bit.bin`` file.

Relies on https://downloads.redpitaya.com/doc/Schematics/Schematics_STEM_125-14_v1.1.pdf to identify
PL pins connected to LEDs.
